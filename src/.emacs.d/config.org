#+TITLE: Alex's Emacs Configuration
#+AUTHOR: Alex Covington

My drop-in Emacs configuration. Please backup your .emacs/.emacs.d before setting anything up.

The config isn't really intended to be modular or user-friendly, and there are a lot of dependencies intertwined with each other and generally highly coupled. There's just assumptions all over the place.

If you need something like more configurable or with more support, I'd recommend [[https://www.spacemacs.org][Spacemacs]] or [[https://github.com/doomemacs/doomemacs][Doom Emacs]].

Quickstart:

#+begin_src sh
  cd <home directory>
  git clone https://github.com/ACov96/dotemacs.git .emacs.d
#+end_src

*NOTE FOR WINDOWS*

Emacs will use =%USERPROFILE%\AppData\Roaming\.emacs.d= if you don't have the =%HOME%= environment variable set to =%USERPROFILE%=.

* Package Management Setup (*NEEDS TO BE FIRST*)

=use-package= is important. It makes maintaining and managing packages and dependencies a breeze while keeping everything literate.

#+begin_src emacs-lisp
  (require 'package)
  (setq package-archives '(("gnu" . "https://elpa.gnu.org/packages/")
                           ("melpa" . "https://melpa.org/packages/")))
  (package-initialize)

  (unless (package-installed-p 'use-package)
    (package-install 'use-package))
#+end_src

* The =alex= Namespace

I write my own utility functions and keep them under the =alex/*= namespace. 

These helpers need to be defined before the rest of the config because other package options will depend on or setup shortcuts/keybindings to helpers.

** Switch Color Themes

Add some helper functions to switch between light and dark mode.

#+begin_src emacs-lisp
  (defun alex/dark-mode () (interactive)
         (color-theme-sanityinc-tomorrow-night))

  (defun alex/light-mode () (interactive)
         (color-theme-sanityinc-tomorrow-day))
#+end_src
** Check OS Platform

Helpers to check the current OS platform

#+begin_src emacs-lisp
  (defun alex/is-windows ()
    (interactive)
    (eq system-type 'windows-nt))
  
  (defun alex/is-linux ()
    (interactive)
    (eq system-type 'gnu/linux))
#+end_src

** =shell= Helpers

=shell= is the most consistent/portable inferior shell mode for me. It works well enough on Windows/Linux that I can reasonably trust it to work anywhere with any shell.

Windows Shells:
- Command Prompt
- PowerShell

#+begin_src emacs-lisp
  (when (alex/is-windows)
    (defun alex/shell-cmd ()
      (interactive)
      (shell "*shell*" (executable-find "cmd.exe")))

    (defun alex/shell-powershell ()
      (interactive)
      (setq explicit-powershell.exe-args '("-NoLogo" "-NoExit"))
      (shell "*shell*" (executable-find "powershell.exe"))))
#+end_src

Linux Shells:
- bash

#+begin_src emacs-lisp
  (when (alex/is-linux)
    (defun alex/shell-bash ()
      (interactive)
      (shell "*shell*" (executable-find "bash"))))
#+end_src

My default shell based on which OS is currently running:
- Windows: =powershell=
- Linux: =bash=

#+begin_src emacs-lisp
  (defun alex/default-shell ()
    (interactive)
    (if (alex/is-windows)
        (alex/shell-powershell)
      (alex/shell-bash)))
#+end_src

* Packages
** =org-mode= Configuration

=org-mode= is the driving force of organizing life with Emacs. Let's make it functional and good looking.

Initialization (needed to make sure =org-mode-hook= fires):

#+begin_src emacs-lisp
  (use-package org
    :ensure t
    :hook
    (text-mode . visual-line-mode)
    :custom
    (org-startup-indented t)
    (org-hide-emphasis-markers 1)
    :config
    ;; Disable auto-indentation in org-mode, conflicts with evil-mode
    (add-hook 'org-mode-hook (lambda () (electric-indent-local-mode -1)))
    (add-hook 'electric-indent-functions (lambda (x) (when (eq 'org-mode major-mode) 'no-indent))))
#+end_src

** General -- Spacebar leader key

Stealing the idea from Spacemacs, let's use the spacebar as a leader key to make using the editor more ergonomic and efficient.

This is the main section of keybindings for the config. Good luck!

#+begin_src emacs-lisp
  (use-package general
    :ensure t
    :config
    (require 'general)
    (general-evil-setup t)
    (nvmap :prefix "SPC"
      "f" 'helm-find-files
      "/" 'split-window-right
      "_" 'split-window-below
      "`" 'alex/default-shell
      "+" 'text-scale-increase
      "-" 'text-scale-decrease
      "b" 'helm-buffers-list
      "s" 'save-buffer
      "d" 'delete-window
      "k" 'kill-buffer
      "w" 'ace-window
      "t" 'treemacs
      "T" 'treemacs-select-window
      "SPC" 'helm-M-x))
#+end_src
